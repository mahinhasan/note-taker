CareGuide API

REST API for notes and posts. Authenticate with Authorization: Bearer <token>.

Auth

  • POST/api/auth/registerpublic
  • POST/api/auth/loginpublic, rate limited

Users

  • GET, PATCH/api/users/meuser, admin
  • GET, POST/api/usersadmin
  • GET/api/users/grouped-by-interestsadmin
  • GET, PATCH, DELETE/api/users/:idadmin
  • GET/api/users/:id/postsuser, admin

Notes

  • GET, POST/api/notesown; admin sees all
  • GET, PATCH, DELETE/api/notes/:idowner or admin

Posts

  • GET, POST/api/postsuser, admin
  • GET/api/posts/:iduser, admin
  • PATCH, DELETE/api/posts/:idauthor or admin
